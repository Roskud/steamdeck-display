# DeckDisplay 🎮🖥️

**DeckDisplay** — это высокопроизводительное программное решение с открытым исходным кодом, превращающее **Steam Deck (LCD и OLED)** в сверхбыстрый проводной второй монитор для ПК на **Windows 10 / 11** по одному кабелю **USB Type-C**.

Проект включает аппаратный Zero-Copy захват рабочего стола, аппаратное кодирование и декодирование видео (NVENC / AMF / QSV на ПК и VA-API RDNA2 на консоли), эмуляцию сенсорного экрана через USB HID с автоматическим учетом физической портретной матрицы дисплея, а также плагин для **Decky Loader** для удобного управления из игрового режима (Gaming Mode).

---

## 🌟 Ключевые возможности

- ⚡ **Сверхнизкая задержка (1–5 мс):** Аппаратный захват кадра из VRAM через **DXGI Desktop Duplication** и прямая передача в аппаратный энкодер без копирования через оперативную память (Zero-Copy).
- 🎯 **Нативное разрешение и частота:** 1280×800 при **90 Гц** (Steam Deck OLED) или **60 Гц** (Steam Deck LCD).
- 👆 **Сенсорный ввод (Touchscreen Digitizer):** Прямая трансляция касаний через эмулируемый в ядре Linux аппаратный USB HID планшет (`/dev/hidg0`) с авто-ротацией координат на 90° и калибровкой в Windows Tablet PC.
- 🔌 **Настоящий Plug & Play:** Автоматическое обнаружение подключения и отключения кабеля USB Type-C на обеих сторонах.
- 🌐 **Сохранение интернет-соединения ПК:** Виртуальный адаптер CDC-NCM выдает IP-адрес без шлюза по умолчанию (`Default Gateway`) и DNS, благодаря чему весь сетевой трафик ПК продолжает бесперебойно идти через Wi-Fi или Ethernet!
- 🚀 **Режим Zero-Build:** Возможность запуска на Windows без установки компиляторов и Visual Studio — через оптимизированный аппаратный конвейер FFmpeg (`ddagrab`).
- 🎮 **Интеграция с Decky Loader:** Фирменное меню быстрых настроек по кнопке `...` в SteamOS с переключателями тачскрина, автозапуска и индикатором соединения.

## 🛠️ Пошаговое руководство по установке

### Шаг 1. Переключение порта USB-C Steam Deck в режим DRD (Dual Role Device)

По умолчанию порт USB-C на Steam Deck сконфигурирован только как хост (для флешек и хабов). Для эмуляции монитора и сетевой карты необходимо переключить контроллер в режим периферии:

1. Полностью выключите Steam Deck.
2. Зажмите кнопку **Громкость +** (`Volume Up`) и нажмите кнопку **Питания**. Отпустите обе кнопки после короткого звукового сигнала.
3. В открывшемся меню выберите **Setup Utility (BIOS)**.
4. Перейдите в раздел **Advanced** → **USB Configuration**.
5. Найдите параметр **USB Dual Role Device** и смените его с `XHCI` на **`DRD`**.
6. Нажмите **F10** (или кнопку меню Select) для сохранения настроек и перезагрузки.

---

### Шаг 2. Установка клиентской части на Steam Deck

1. Перейдите в **Режим рабочего стола (Desktop Mode)**: нажмите кнопку `STEAM` → `Выключение` → `Перейти к рабочему столу`.
2. Скопируйте папку проекта на Steam Deck (например, в `/home/deck/deckdisplay`).
3. Откройте терминал **Konsole** и выполните автоматический установщик:
   ```bash
   cd /home/deck/deckdisplay/steamos-client
   chmod +x install-steamos.sh
   ./install-steamos.sh
   ```
   *Скрипт автоматически отключит readonly-режим SteamOS, установит необходимые библиотеки (`gcc`, `sdl2`, `ffmpeg`, `dnsmasq`), скомпилирует бинарники, создаст системный сервис `deckdisplay-gadget.service` и поместит ярлык на Рабочий стол.*

4. **Добавление в библиотеку Steam (для запуска из Gaming Mode):**
   - Откройте клиент Steam на Рабочем столе.
   - В верхнем меню выберите: `Игры` → `Добавить стороннюю игру в библиотеку...`.
   - Нажмите `Обзор...` и укажите путь: `/home/deck/deckdisplay/steamos-client/launch_deckdisplay.sh`.
   - В свойствах добавленной игры можно переименовать её в **DeckDisplay** и задать иконку.

---

### Шаг 3. Настройка виртуального монитора на ПК (Windows 10/11)

Чтобы Windows могла выводить второй рабочий стол, необходимо создать виртуальный видеовыход:

1. Откройте папку `virtual-display` на ПК.
2. Запустите скрипт **`setup-virtual-display.ps1`** от имени Администратора:
   - Скрипт создаст каталог `C:\IddSampleDriver` и скопирует туда конфигурацию `option.txt` с нативным разрешением Steam Deck: `1280x800` с частотой `60` и `90` Гц.
3. Скачайте последнюю версию драйвера **Virtual Display Driver (IddSampleDriver / MTT)**:
   - Репозиторий GitHub: [itsmikethetech/Virtual-Display-Driver Releases](https://github.com/itsmikethetech/Virtual-Display-Driver/releases)
4. Распакуйте скачанный архив драйвера в `C:\IddSampleDriver` и запустите `Install.bat` от имени Администратора.
5. В параметрах дисплея Windows (`Параметры` → `Система` → `Дисплей`) появится второй монитор. Установите для него разрешение **1280 × 800** и частоту обновления **90 Гц** (для OLED) или **60 Гц** (для LCD).

---

### Шаг 4. Калибровка сенсорного экрана в Windows (выполняется 1 раз)

Windows должна знать, к какому именно монитору относится сенсорное устройство Steam Deck:

1. Соедините включенный Steam Deck и ПК кабелем USB Type-C.
2. На ПК в папке `virtual-display` запустите файл **`calibrate-touch.bat`** (или нажмите `Win + R` и введите `control tabletpc.cpl`).
3. В открывшемся окне нажмите кнопку **Настройка... (Setup...)**.
4. Нажимайте клавишу **Enter**, пока белый экран с запросом *«Коснитесь этого экрана одним пальцем»* не переместится на дисплей Steam Deck.
5. Один раз коснитесь экрана Steam Deck пальцем.
6. Windows запомнит привязку тачскрина к виртуальному монитору 1280×800 навсегда!

---

### Шаг 5. Повседневный запуск

1. **На ПК:** Запустите **`run-deckdisplay.bat`** (или `Start-DeckDisplay.ps1`). Вотчдог перейдет в режим ожидания подключения консоли.
2. **На Steam Deck:** Вставьте кабель USB Type-C в ПК и запустите ярлык **DeckDisplay** в игровом режиме SteamOS.
3. Рабочий стол Windows мгновенно появится на экране Steam Deck! При отключении кабеля клиент автоматически закроется и вернет вас в интерфейс Steam.

## 🔌 Установка плагина для Decky Loader (по желанию)

Если у вас установлен **Decky Loader**, вы можете управлять DeckDisplay прямо из бокового меню `...`:

1. На Steam Deck перейдите в папку плагина:
   ```bash
   cd /home/deck/deckdisplay/decky-plugin
   chmod +x build-plugin.sh deploy-plugin.sh
   ./deploy-plugin.sh
   ```
2. Откройте быстрое меню `...` в игровом режиме, перейдите на вкладку плагинов (иконка вилки) и выберите **DeckDisplay**.
3. При активной опции **«Автозапуск при подключении кабеля»** монитор будет разворачиваться сам в момент подключения провода USB-C!

## ⚙️ Тонкая настройка и параметры запуска

Скрипт `Start-DeckDisplay.ps1` поддерживает следующие параметры командной строки:

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `-DeckIP` | `10.77.77.2` | IP-адрес Steam Deck на виртуальном адаптере |
| `-Port` | `5000` | UDP-порт для передачи видеопотока |
| `-OutputIdx` | `1` | Индекс захватываемого монитора (`0` = основной, `1` = виртуальный IddCx) |
| `-Framerate` | `90` | Целевой фреймрейт (`90` для OLED, `60` для LCD) |
| `-Encoder` | `auto` | Энкодер: `auto`, `h264_nvenc`, `h264_amf`, `h264_qsv`, `libx264` |
| `-Bitrate` | `45M` | Битрейт потока (для идеальной четкости текста рекомендуется 35M–60M) |

Пример запуска с принудительным энкодером AMD и частотой 60 Гц:
```powershell
powershell -ExecutionPolicy Bypass -File .\Start-DeckDisplay.ps1 -Framerate 60 -Encoder h264_amf -Bitrate 50M
```

## 🔧 Диагностика и решение проблем

| Симптом | Вероятная причина | Решение |
| :--- | :--- | :--- |
| `Не найден контроллер в /sys/class/udc` | В BIOS порт USB-C остался в режиме хоста (`XHCI`). | Перезагрузите Deck с зажатой `Volume +`, откройте Setup Utility → Advanced → USB Configuration и переключите `USB Dual Role Device` в **DRD**. |
| Касания на Deck кликают по основному монитору ПК | Тачскрин Windows привязан к монитору #1 по умолчанию. | Запустите `virtual-display/calibrate-touch.bat`, нажмите «Настройка...», нажмите `Enter` до экрана Deck и коснитесь его один раз. |
| Черный экран или задержка при старте | Пропущен первый ключевой кадр H.264. | Убедитесь, что в `Start-DeckDisplay.ps1` установлен фреймрейт, соответствующий экрану (60/90). Сервер автоматически отправляет IDR кадр раз в секунду. |
| ПК потерял интернет при подключении Deck | DHCP-сервер выдал Windows адрес шлюза по умолчанию. | В `deckdisplay-gadget.sh` параметры `--dhcp-option=3` и `6` предотвращают это. Проверьте `Get-NetIPConfiguration` на ПК — шлюз на адаптере UsbNcm должен отсутствовать. |
| После обновления SteamOS пропали `dnsmasq` или `sdl2` | Обновление образа SteamOS A/B перезаписало корневой раздел. | Повторно запустите `install-steamos.sh` из папки `steamos-client`. Папка `/home/deck/` при системных обновлениях сохраняется в неизменном виде. |
