# DeckDisplay 🎮🖥️

**DeckDisplay** is a high-performance open-source solution that turns your **Steam Deck** into a fast, wired secondary monitor for your PC via USB-C cable.

[Русская версия](README.md)

---

## 🚀 Installation

### Option 1: Decky Loader Plugin (Recommended for SteamOS)
The best way to integrate with the system.
1. Install **Decky Loader** on your Steam Deck.
2. Download `DeckDisplay_Plugin.zip` from [Releases](https://github.com/Roskud/steamdeck-display/releases).
3. Move the archive to `/home/deck/homebrew/plugins/` or use the USB install feature in Decky.

### Option 2: Portable Client (No Installation)
If you don't want to use Decky:
1. Download `DeckDisplay_Static.tar.gz`.
2. Extract it on your Steam Deck.
3. Run `launch_deckdisplay.sh`.

---

## 💻 For PC (Windows)
1. Download [DeckDisplay.exe](https://github.com/Roskud/steamdeck-display/releases).
2. Run it and connect your Steam Deck via USB-C.
